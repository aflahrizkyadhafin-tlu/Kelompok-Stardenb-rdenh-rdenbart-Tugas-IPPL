Spesifikasi API Endpoint Baru untuk Melengkapi Skema Database MyKurir

LaporanController

Menangani semua fungsi pelaporan atau komplain antar pengguna sistem (misalnya Pelanggan melaporkan Kurir, atau sebaliknya). Controller ini memetakan data langsung ke tabel public.laporan dan mengelola relasi ganda terhadap tabel public.akun.

Aturan Validasi Keamanan & Sesi: Field reporter_id TIDAK BOLEH dikirim melalui body request oleh client. Backend wajib mengambil UUID dari payload token JWT atau sesi autentikasi pengguna aktif untuk menghindari manipulasi identitas pelapor.
Endpoint & Method Fungsi & Payload Otorisasi Akses
POST /api/laporan buatLaporan()
Membuat entri komplain baru di database.
Lihat JSON Payload 
{
  "reported_id": "d3b07384-d113-4c4e-9c8e-cf1234567890",
  "pesan": "Kurir tidak ramah dan paket dilempar ke pagar halaman."
}
 Pelanggan Kurir
GET /api/laporan/me getLaporanSaya()
Mengambil semua riwayat laporan yang pernah dikirim oleh pengguna saat ini (Filter: reporter_id = auth.uid()). 		Pelanggan Kurir
GET /api/admin/laporan getAllLaporan()
Menampilkan seluruh laporan masuk untuk tim Admin. Query harus melakukan JOIN sebanyak dua kali ke tabel akun untuk mengambil data nama_lengkap pelapor dan terlapor. 		Admin
GET /api/admin/laporan/:id getDetailLaporan(id)
Mengambil satu record laporan secara mendalam beserta detail kontak dari kedua belah pihak untuk keperluan investigasi. 		Admin
DELETE /api/admin/laporan/:id hapusLaporan(id)
Menghapus pengajuan laporan dari database apabila masalah dinyatakan selesai (resolved) atau terbukti sebagai laporan palsu (spam). 		Admin

DokumenDriverController

Bertanggung jawab atas manajemen berkas administrasi dan verifikasi dokumen legalitas kurir. Controller ini memproses data pada tabel public.dokumen_driver yang menyimpan status validasi (pending, approved, rejected) serta tautan penyimpanan awan untuk KTP dan SIM.

Alur Kerja Cloud Storage: Backend tidak menerima file raw biner pada endpoint ini. Aplikasi mobile/frontend mengunggah file gambar ke objek storage (misal Supabase Bucket) terlebih dahulu, kemudian mengirimkan string URL publiknya ke API ini.
Endpoint & Method Fungsi & Payload Otorisasi Akses
POST /api/driver/dokumen uploadDokumen()
Mengajukan berkas baru untuk diverifikasi. Field status di tingkat database otomatis di-set ke pending lewat default constraint.
Lihat JSON Payload 
{
  "kartu_identitas": "https://storage.mykurir.com/ktp/user-771.jpg",
  "surat_izin_mengemudi": "https://storage.mykurir.com/sim/user-771.jpg"
}
 Kurir (Calon)
GET /api/driver/dokumen/status cekStatusDokumen()
Mengecek status terkini verifikasi dokumen milik driver yang sedang login (apakah disetujui, ditolak, atau masih diproses). 		Kurir
PUT /api/driver/dokumen perbaruiDokumen()
Mengunggah ulang berkas perbaikan apabila pendaftaran sebelumnya ditolak oleh admin. Aksi ini otomatis mengembalikan status menjadi pending. 		Kurir
GET /api/admin/dokumen/pending getDokumenPending()
Menampilkan antrean seluruh dokumen calon kurir yang berstatus pending untuk segera diperiksa oleh tim Admin. 		Admin
PUT /api/admin/dokumen/:id/verifikasi verifikasiDokumen(id)
Mengubah status dokumen kurir. Jika status dirubah menjadi 'approved', sistem disarankan memicu perubahan status kurir menjadi aktif secara otomatis.
Lihat JSON Payload 
{
  "status": "approved" // atau 'rejected'
}
 Admin

RatingAplikasiController

Mengelola umpan balik global pengguna terhadap kualitas platform aplikasi MyKurir secara keseluruhan. Terpisah dari ulasan performa kurir jalanan, data ini mendarat di tabel public.rating_aplikasi.

Endpoint & Method Fungsi & Payload Otorisasi Akses
POST /api/rating-aplikasi buatRating()
Menyimpan ulasan baru dari pengguna aplikasi. Nilai skor mendukung tipe data pecahan desimal (real).
Lihat JSON Payload 
{
  "skor": 4.5,
  "pesan": "UI aplikasi sangat responsif, tapi pelacakan peta perlu sedikit akurasi tambahan."
}
 Pelanggan Kurir
GET /api/rating-aplikasi/me getRatingSaya()
Membaca ulasan yang pernah dikirimkan oleh pengguna terkait guna ditampilkan di halaman profil mereka masing-masing. 		Pelanggan Kurir
GET /api/admin/rating-aplikasi getAllRating()
Mengambil seluruh rekaman rating dari semua pengguna aplikasi, diurutkan dari yang paling baru (created_at DESC). 		Admin
GET /api/admin/rating-aplikasi/statistik getStatistikRating()
Menghitung agregasi data untuk ringkasan visual Dashboard Admin. Output berupa rata-rata nilai bintang (AVG skor) dan total distribusi rating. 		Admin
DELETE /api/admin/rating-aplikasi/:id hapusRating(id)
Menghapus paksa ulasan dari database apabila mengandung unsur spam, ujaran kebencian, atau kata-kata yang melanggar ketentuan platform. 		Admin

Integritas Relasi Database

Dokumen ini dibuat untuk melengkapi spesifikasi controller utama yang telah diimplementasikan sebelumnya. Semua controller di atas wajib mematuhi skema foreign key constraint yang didefinisikan pada database PostgreSQL/Supabase Anda guna mencegah adanya kegagalan referensi data (orphan records).
